CAPSÉRA extracted visual assets
=================================

These files are crops from the supplied 1024x1536 CAPSÉRA website reference image.

Folders:
- section-backgrounds: section-level crops for visual reference.
- hero-items: hero blister pack, floating capsule cluster, and benefit area.
- skin-type-items: five skin-type droplet cards.
- seven-step-capsules: seven product-card crops.
- how-to-use-items: four instruction-image crops.
- icons-and-details: header, service, footer, and water-decoration crops.

Important:
The source is a single flattened screenshot, so these are cropped JPGs and may include nearby text/background. They are not original isolated transparent PNG assets, and section-background crops still contain the content shown in the screenshot. For clean backgrounds or transparent individual product cutouts, recreate/obtain separate source artwork.
